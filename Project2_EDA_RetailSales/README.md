# Exploratory Data Analysis (EDA) on Retail Sales Data

## Project Overview
Performed Exploratory Data Analysis on a real-world Retail Sales Dataset as part of Data Analytics Internship at Oasis Infobyte.

## Dataset
- retail_sales_dataset.csv

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Data Loading and Cleaning
2. Descriptive Statistics (Mean, Median, Mode)
3. Time Series Analysis
4. Customer and Product Analysis
5. Data Visualization

## Key Findings
- Clothing and Electronics had highest total sales
- Customers aged 25-45 are the biggest buyers
- Monthly sales trends revealed peak buying seasons
