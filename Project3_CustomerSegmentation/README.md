# Customer Segmentation Analysis

## Project Overview
Performed Customer Segmentation Analysis for an e-commerce company as part of Data Analytics Internship at Oasis Infobyte. The goal is to group customers into distinct segments based on behavior and purchase patterns using K-Means Clustering.

## Dataset
- ifood_df.csv (2205 customers, 39 features)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Key Concepts
1. Data Exploration and Cleaning
2. Descriptive Statistics
3. Feature Engineering
4. K-Means Clustering Algorithm
5. Principal Component Analysis (PCA)
6. Elbow Method and Silhouette Score
7. Data Visualization

## Key Findings
- Optimal number of clusters = 4
- Cluster 0: High income customers in relationship (High spenders)
- Cluster 1: Low income single customers (Low spenders)
- Cluster 2: High income single customers (High spenders)
- Cluster 3: Low income customers in relationship (Low spenders)

## Cluster Characteristics
| Cluster | Income Level | Relationship | Spending |
|---------|-------------|--------------|---------|
| 0 | High | Yes | High |
| 1 | Low | No | Low |
| 2 | High | No | High |
| 3 | Low | Yes | Low |
