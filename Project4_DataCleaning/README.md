# Data Cleaning

## Project Overview
Performed Data Cleaning on real-world datasets as part of 
Data Analytics Internship at Oasis Infobyte. Data cleaning 
is the process of fixing or removing incorrect, corrupted, 
duplicate, or incomplete data within a dataset.

## Datasets
- AB_NYC_2019.csv (New York City Airbnb listings)
- USvideos.csv (YouTube trending videos)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Data Integrity Check
2. Missing Data Handling
3. Duplicate Removal
4. Standardization
5. Outlier Detection and Visualization

## Key Findings
- Airbnb dataset had missing values in reviews column
- YouTube dataset had duplicate video entries
- Price outliers detected in Airbnb listings
- Data standardized for accurate analysis
