# Fraud Detection

## Project Overview
Built a Fraud Detection system to identify fraudulent credit 
card transactions using Machine Learning as part of Data 
Analytics Internship at Oasis Infobyte. Leverages anomaly 
detection and pattern recognition techniques.

## Dataset
- creditcard.csv (284,807 credit card transactions)
- Class 0 = Legitimate Transaction
- Class 1 = Fraudulent Transaction

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Anomaly Detection
2. Feature Engineering and Scaling
3. Handling Imbalanced Data (Undersampling)
4. Logistic Regression
5. Decision Tree Classifier
6. Neural Network (MLP Classifier)
7. Confusion Matrix Analysis
8. Algorithm Comparison

## Key Findings
- Dataset is highly imbalanced (fraud is rare)
- Undersampling used to balance the dataset
- All 3 models successfully detected fraud transactions
- Confusion matrix used to evaluate false positives and negatives

## Models Used
| Model | Description |
|-------|-------------|
| Logistic Regression | Linear classification model |
| Decision Tree | Tree based classification model |
| Neural Network | Multi layer perceptron model |
