# Sentiment Analysis

## Project Overview
Developed a Sentiment Analysis model to classify text data 
as Positive, Negative or Neutral as part of Data Analytics 
Internship at Oasis Infobyte. Provides insights into public 
opinion and customer feedback.

## Datasets
- Twitter_Data.csv (Tweets with sentiment labels)
- user_reviews.csv (Google Play Store reviews)

## Tools Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Natural Language Processing (NLP)
2. Text Preprocessing and Cleaning
3. TF-IDF Feature Extraction
4. Naive Bayes Classification
5. Logistic Regression
6. Support Vector Machine (SVM)
7. Algorithm Comparison

## Key Findings
- Successfully classified tweets as Positive, Negative, Neutral
- TF-IDF used for feature extraction from text
- Multiple ML algorithms compared for best accuracy
- Word frequency analysis revealed common positive and negative words
