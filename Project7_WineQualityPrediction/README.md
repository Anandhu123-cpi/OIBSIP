# Wine Quality Prediction

## Project Overview
Built a Wine Quality Prediction system using multiple 
classifier models based on chemical characteristics of wine 
as part of Data Analytics Internship at Oasis Infobyte.

## Dataset
- WineQT.csv (1143 wine samples with 13 chemical features)

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Data Exploration and Visualization
2. Feature Engineering
3. Random Forest Classifier
4. Stochastic Gradient Descent (SGD)
5. Support Vector Machine (SVM)
6. Algorithm Comparison
7. Feature Importance Analysis

## Key Findings
- Alcohol content is the most important feature for quality
- Random Forest achieved highest accuracy among all models
- Higher alcohol percentage correlates with better wine quality
- Density and acidity are strong predictors of wine quality

## Models Used
| Model | Description |
|-------|-------------|
| Random Forest | Ensemble of decision trees |
| SGD Classifier | Gradient descent based model |
| SVM Classifier | Support vector based model |
