# Predicting House Prices with Linear Regression

## Project Overview
Built a predictive model using Linear Regression to estimate 
house prices based on relevant features as part of Data 
Analytics Internship at Oasis Infobyte.

## Dataset
- Housing.csv (545 houses with 13 features)

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Key Concepts
1. Data Exploration and Cleaning
2. Feature Selection and Encoding
3. Linear Regression Model Training
4. Model Evaluation (MSE, RMSE, MAE, R²)
5. Actual vs Predicted Visualization
6. Residual Analysis
7. Feature Importance

## Key Findings
- Area and number of bathrooms are top price predictors
- Furnished houses have significantly higher prices
- Model achieved good R² score on test data
- Linear Regression successfully predicts house prices

## Model Performance
- Evaluated using MSE, RMSE, MAE and R² Score
- Visualized actual vs predicted prices
- Residual plot confirmed model reliability
